## 1. 로그인

1. **https://www.kesri.co.kr/admin** 접속
2. 관리자 이메일 + 비밀번호 입력 → **관리자 로그인** 클릭
3. 로그인 후 → **관리자 대시보드** 자동 이동

> 로그인이 안 될 경우 → [6. 오류 해결](#6-오류-해결) 참고

## 3. 공지사항 관리

### 3-1. 공지사항 새로 쓰기

**경로**: 대시보드 → `새 공지 작성` 버튼  
또는 상단 메뉴 `공지사항 관리` → 우측 상단 `+ 새 소식 작성` 버튼

---

**① 카테고리 선택** (드롭다운 첫 번째 항목)

| 선택값 | 표시 | 사용 상황 |
|--------|------|-----------|
| 일반 | 🔵 일반 | 일상 안내, 소식 |
| 중요 | 🔴 중요 | 정책 변경, 주요 공지 |
| 이벤트 | 🟢 이벤트 | 행사, 세미나, 교육 |
| 긴급 | 🟠 긴급 | 시스템 점검, 응급 상황 |

---

**② 제목 입력**
- 명확하고 짧게 (20자 이내 권장)
- 예: `2026년 추석 연휴 휴무 안내`

---

**③ 내용 입력**
- 본문 전체 내용 작성
- Enter로 줄바꿈

---

**④ 옵션 설정** (작성 폼 하단)

| 옵션 | 체크 시 효과 |
|------|-------------|
| ☐ 핀 고정 | 공지 목록 맨 위에 고정 표시 |
| ☐ 팝업 공지 | 홈 방문 시 팝업으로 노출 |

---

**⑤ 저장**
- 하단 `저장` 버튼 클릭
- 저장 즉시 홈페이지에 반영됨 (배포 불필요)
- 저장 후 공지사항 관리 목록으로 자동 이동

---

### 3-2. 공지사항 수정

1. 상단 메뉴 `공지사항 관리` 클릭
2. 수정할 공지 카드에서 **`수정`** 버튼 클릭
3. 내용 변경 후 **`저장`** 클릭

> ℹ️ 작성일시·작성자는 수정 불가

---

### 3-3. 공지사항 삭제

⚠️ **삭제 후 복구 불가**

1. `공지사항 관리` 목록에서 삭제할 공지 카드 찾기
2. **`삭제`** 버튼 클릭
3. 확인창 → **`확인`** 클릭 → 즉시 삭제

---

### 3-4. 핀 고정

- 핀 고정된 공지는 게시판 목록 **최상단에 고정**됨
- 공지 작성/수정 화면에서 **`핀 고정` 체크박스**로 변경

**운영 원칙**
- 동시에 **3개 이하** 유지
- 행사·점검 종료 후 즉시 핀 해제
- 매주 1회 핀 고정 목록 검토 권장

## 4. 팝업 공지 관리

홈페이지 방문 시 화면 가운데 표시되는 팝업입니다.

```
홈(/) 접속
    ↓
팝업 ON 상태인 공지 있음?
    ├── YES → 방문자가 오늘 "보지 않기" 눌렀나?
    │           ├── NO  → 팝업 표시
    │           └── YES → 팝업 숨김 (다음날 다시 표시)
    └── NO  → 팝업 없음
```

> ⚠️ 팝업은 **최대 1개**만 활성화 가능. 새 팝업을 켜면 기존 팝업은 자동 꺼짐.

---

### 4-1. 팝업 켜기

1. `공지사항 관리` → `새 소식 작성` (또는 기존 공지 `수정`)
2. 작성 폼 하단 **`팝업 공지`** 체크박스 ✅ 체크
3. `저장` → 홈 방문 시 즉시 팝업 표시

**팝업으로 쓰기 좋은 공지 예시**
- 명절 휴무 안내
- 홈페이지 점검 예고
- 신규 서비스 오픈

---

### 4-2. 팝업 끄기

1. 현재 팝업 중인 공지 찾기 (`공지사항 관리` 목록에서 확인)
2. 해당 공지 **`수정`** 클릭
3. **`팝업 공지`** 체크박스 ☐ 해제
4. `저장` → 즉시 팝업 미표시

---

### 4-3. 팝업 확인 방법

1. 상단 `홈페이지로` 클릭
2. **시크릿 창**(Ctrl+Shift+N)에서 `https://www.kesri.co.kr` 접속
   - 일반 창은 "오늘 하루 보지 않기"가 남아 있어 팝업이 안 보일 수 있음

---

## 5. 정기 운영 루틴

### 매일 확인
- [ ] 팝업 공지 유효 여부 확인 (기간 지난 공지 팝업 OFF)

### 매주 확인
- [ ] 핀 고정 목록 검토 → 불필요한 것 해제
- [ ] 오래된 공지 중 삭제 또는 비공개 처리 검토

### 행사·점검 전
- [ ] 관련 공지 작성 + 핀 고정 + 팝업 ON
- [ ] 홈페이지에서 실제 노출 확인 (시크릿 창)

### 행사·점검 후
- [ ] 팝업 끄기
- [ ] 핀 고정 해제
- [ ] 필요 시 완료 공지 작성

## 6. 오류 해결

### 로그인이 안 될 때

| 증상 | 해결 |
|------|------|
| "잘못된 이메일 또는 비밀번호" | 이메일·비밀번호 재확인, 대소문자 주의 |
| 로그인해도 관리자 메뉴 없음 | 기술 담당자에게 이메일 등록 요청 |
| 비밀번호를 잊어버림 | 로그인 화면 하단 `비밀번호 찾기` 사용 |

### 공지 저장이 안 될 때

| 증상 | 해결 |
|------|------|
| 저장 버튼 눌러도 반응 없음 | 제목·내용 입력 여부 확인 |
| 저장 후 목록에 안 보임 | Ctrl+Shift+R 강력 새로고침 |
| "저장에 실패했습니다" 메시지 | 인터넷 연결 확인 후 재시도 |

### 팝업이 안 보일 때

| 증상 | 해결 |
|------|------|
| 팝업 ON인데 홈에 안 보임 | 시크릿 창으로 확인 (일반 창은 "오늘 그만보기" 캐시 있음) |
| 팝업 설정했는데 여전히 없음 | 저장 완료 여부 재확인 |

### 웹사이트 자체가 안 열릴 때

1. https://status.vercel.com 접속 → Vercel 서버 상태 확인
2. 다른 기기·네트워크에서 시도
3. 이상 없으면 기술 담당자에게 연락
