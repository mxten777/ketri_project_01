## 🔄 사용자 플로우 (User Flow)

### 시나리오 1: 서비스 정보 조회

```
1. 홈페이지 접속
   ↓
2. 메인 메뉴에서 원하는 서비스 선택 (예: 먹는물 검사)
   ↓
3. 서비스 상세 페이지 확인
   - 업무소개
   - 검사대상 및 범위
   - 수수료
   - 의뢰 절차
   ↓
4. 필요시 연락처로 문의
```

### 시나리오 2: 공지사항 확인

```
1. 홈페이지 접속
   ↓
2. 메인 화면 "최신 공지사항" 섹션 확인
   또는
   "정보센터 > 공지사항" 메뉴 클릭
   ↓
3. 공지사항 목록 확인
   ↓
4. 원하는 공지사항 클릭하여 상세 내용 확인
   ↓
5. 첨부파일 다운로드 (있는 경우)
```

### 시나리오 3: 관리자 - 공지사항 작성

```
1. 관리자 로그인 페이지 접속 (/admin/login)
   ↓
2. 이메일/비밀번호 입력하여 로그인
   ↓
3. 공지사항 관리 페이지 (/admin/notice)
   ↓
4. "새 글 작성" 버튼 클릭
   ↓
5. 작성 페이지에서 내용 입력
   - 제목
   - 본문 (Rich Text Editor)
   - 이미지 업로드
   - 중요 공지 설정
   ↓
6. "발행" 버튼 클릭
   ↓
7. Firebase에 저장 및 공지사항 목록에 표시
```
