## 2. 원인 분석 (복합 3가지)

### 원인 A — CSS 캐스케이드 충돌: 헤더 `position: fixed` 무력화 ⭐ 주요

**파일**: `src/index.css`

`@layer` 밖(비레이어, un-layered CSS)에 아래 코드가 존재:

```css
/* src/index.css (수정 전) */
header {
  min-height: var(--app-header-h, 72px);
  display: block;
  position: relative;   /* ← 문제 */
  isolation: isolate;
  ...
}
```

**CSS 캐스케이드 우선순위** 규칙에 따라 un-layered 스타일은 `@layer utilities`보다 **항상 높은 우선순위**를 가집니다.  
Tailwind의 `.fixed { position: fixed; }` 는 `@layer utilities` 안에 있으므로,  
`header { position: relative }` 가 이를 **완전히 덮어쓰고** 있었습니다.

> 결과: 헤더가 `position: fixed`가 아닌 `position: relative`로 렌더링됨  
> → 페이지 스크롤 시 로고를 포함한 헤더 전체가 본문과 함께 위로 사라짐

---

### 원인 B — 로고 이미지 CSS 사이징 모호성 ⭐ 직접 원인

**파일**: `src/index.css`

```css
/* src/index.css (수정 전) */
header img[alt="한국환경안전연구소"] {
  max-height: calc(var(--app-header-h) - 18px) !important;
  height: auto !important;   /* ← 모호한 auto */
  width: auto !important;
  ...
}
```

**구 로고 파일** `logo_horizontal.png` (340×74 px) — 자연 높이 74px < max-height ~70px → max-height 적용되어 정상 표시  
**신 로고 파일** `680px_logo_trans.png` (680×148 px) — 자연 높이 148px >> max-height ~70px  

`height: auto` + `max-height` 조합에서 브라우저가 비례(aspect-ratio) 계산을 할 때,  
이미지 자연 크기가 컨테이너보다 **2배 이상 크면** 일부 브라우저/렌더링 엔진에서 계산이 불안정해져  
높이가 0 또는 비정상 값으로 결정되는 문제가 발생합니다.

#### 로고 파일 색상 확인

픽셀 분석 결과:

| 파일 | 크기 | 주색상 | 흰 배경 가시성 |
|---|---|---|---|
| `680px_logo_trans.png` | 680×148 | 파란색 (#044D8F), 녹색 (#A2C225) | ✅ 가시 (색상 정상) |
| `680px_logo_dark.png` | 680×148 | 파란색 (#004D90) | ✅ 가시 |
| `680px_logo_white.png` | 680×148 | 백색 (#FFFFFF) | ❌ 흰 배경 불가 (다크모드 전용) |

> 로고 색상은 정상이며 흰 배경에 묻히는 문제는 아님.  
> 사이징 렌더링 실패로 높이가 0이 되어 보이지 않은 것.

### 원인 C — 플렉스 컨테이너에서 로고 `flex-shrink` 미지정

**파일**: `src/components/layout/HeaderHero.tsx`

```tsx
/* 수정 전 */
<Link className="flex items-center py-2 transition-transform hover:scale-[1.02]">
  <img className="h-12 md:h-14 w-auto object-contain" ... />
```

헤더 내비게이션이 `justify-between` 플렉스 컨테이너이며,  
메뉴 링크들은 `whitespace-nowrap`으로 축소 방지가 되어 있지만  
로고 `<Link>` wrapper에 `flex-shrink: 0`(Tailwind: `shrink-0`)이 없었습니다.

> 결과: 뷰포트가 좁아질 때 플렉스 레이아웃이 로고를 0px로 압축 가능

## 3. 수정 내역

### 수정 파일 1: `src/index.css`

#### 변경 A — `position: relative` 제거

```css
/* 수정 전 */
header {
  min-height: var(--app-header-h, 72px);
  display: block;
  position: relative;   /* ← 삭제 */
  isolation: isolate;
  ...
}

/* 수정 후 */
header {
  /* NOTE: Do NOT set position here — Tailwind .fixed in @layer utilities
     would be overridden by un-layered CSS. Keep position unset. */
  min-height: var(--app-header-h, 72px);
  display: block;
  isolation: isolate;
  ...
}
```

#### 변경 B — 로고 CSS: 명시적 높이 토큰 사용

```css
/* 수정 전 */
header img[alt="한국환경안전연구소"] {
  max-height: calc(var(--app-header-h) - 18px) !important;
  height: auto !important;
  width: auto !important;
  ...
}

/* 수정 후 */
header img[alt="한국환경안전연구소"] {
  height: var(--logo-height) !important;   /* 토큰 기반 명시적 높이 */
  width: auto !important;                   /* 비례 폭 자동 계산 */
  max-width: none !important;              /* 수평 클리핑 방지 */
  flex-shrink: 0 !important;              /* 플렉스 압축 방지 */
  visibility: visible !important;
  ...
}
```

> `--logo-height` 토큰값: 모바일 36px / 태블릿 40px / 데스크탑 44px (`src/index.css` `:root` 정의)

---

### 수정 파일 2: `src/components/layout/HeaderHero.tsx`

```tsx
/* 수정 전 */
<Link
  to="/"
  className="flex items-center py-2 transition-transform hover:scale-[1.02]"
>
  <img
    src={...}
    alt="한국환경안전연구소"
    width={200}
    height={48}
    className="h-12 md:h-14 w-auto object-contain"
  />
</Link>

/* 수정 후 */
<Link
  to="/"
  className="flex items-center py-2 transition-transform hover:scale-[1.02] shrink-0"
>
  <img
    src={...}
    alt="한국환경안전연구소"
    width={200}
    height={48}
    className="w-auto object-contain"
    style={{ height: "var(--logo-height, 36px)", minWidth: 80, display: "block" }}
  />
</Link>
```

## 5. 재발 방지 방법

| 위험 패턴 | 방지 방법 |
|---|---|
| `@layer` 밖 `position` 설정 → Tailwind 위치 클래스 무력화 | 헤더·레이아웃 요소의 `position`은 **Tailwind 클래스로만 관리** (CSS에서 직접 설정 금지) |
| `height: auto` + `max-height` 조합 → 자연 크기가 큰 이미지에서 불안정 | 로고 등 중요한 이미지는 **`height: var(--logo-height)` 토큰으로 명시적 지정** |
| 플렉스 컨테이너 내 로고에 `shrink-0` 누락 | 헤더 내 로고 wrapper에 항상 **`shrink-0`** 또는 `min-width` 지정 |
| 로고 파일 교체 시 CSS 호환 미확인 | 새 로고 파일 교체 후 `naturalWidth` / `naturalHeight`가 이전 파일과 크게 다르면 CSS 사이징 규칙 재검토 필수 |
