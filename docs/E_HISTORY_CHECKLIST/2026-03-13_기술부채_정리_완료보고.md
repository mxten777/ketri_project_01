## 2. 작업 항목 및 처리 결과

### 2-1. CSS 중복 규칙 제거 — `src/index.css`

**문제:**  
`src/index.css` 하단의 `@layer utilities { ... }` 블록(약 80줄)이 파일 상단의 un-layered 헤더 규칙과 완전히 중복되어 있었다.  
이 블록은 `!important`를 과도하게 사용하면서 실제 적용 우선순위에서도 충돌을 일으키는 원인이었다.

**조치:**  
중복 `@layer utilities` 헤더 블록 전체 제거.  
상단의 un-layered 규칙이 단일 진실 공급원(Single Source of Truth)으로 동작하도록 정리.
