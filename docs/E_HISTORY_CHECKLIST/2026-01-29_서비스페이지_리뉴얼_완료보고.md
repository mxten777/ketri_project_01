Hero: py-16 lg:py-20

Section Card: p-8

## 🔧 QA 및 수정 작업

### CTA 위치 통일
**대상**: WorkEnvironment, AsbestosSurvey  
**문제**: ServiceCta가 grid 내부에 위치  
**해결**: Grid 외부로 이동, `<div className="mt-8">` 래퍼로 감싸기

**수정 전**:
```tsx
</section>
</div>
<ServiceCta /> // grid 내부
</div>
```

**수정 후**:
```tsx
</section>
</div>
</div>
<div className="mt-8">
  <ServiceCta />
</div>
```

### 구조 일관성 확인
- ✅ Hero Section: 모든 페이지 `py-16 lg:py-20`
- ✅ Main Container: 모든 페이지 `py-12 lg:py-16`
- ✅ Grid: `lg:grid-cols-4` (Sidebar 1 + Main 3)
- ✅ Section 간격: `space-y-10`
- ✅ CTA 위치: Grid 외부, mt-8

## 📱 모바일 반응형

### 적용된 반응형 클래스
```css
/* Typography */
text-4xl lg:text-5xl (Hero 제목)
text-lg lg:text-xl (Hero 부제)
text-2xl (섹션 제목)
text-base (본문)

/* Layout */
grid-cols-1 lg:grid-cols-4 (메인 그리드)
grid-cols-1 md:grid-cols-2 (카드 그리드)
py-16 lg:py-20 (Hero)
py-12 lg:py-16 (Main)

/* Sidebar */
sticky top-24 (데스크톱)
모바일: 일반 블록으로 표시
```

### 모바일 최적화
- 프로세스 배지: 세로 스택 구조
- 표: 가로 스크롤 (`overflow-x-auto`)
- 카드: 단일 열로 전환
- 네비게이션: 탭처럼 동작
