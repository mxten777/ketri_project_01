### 1. 지도 시스템 개선

#### 변경 파일: `src/constants/menu.ts`

**변경 전 문제점**:
- 지도 좌표가 여러 파일에 하드코딩되어 있음
- Google Maps iframe이 좌표 기반으로 표시되어 플러스코드(HF8Q+PQH) 노출
- zoom=16으로 너무 멀게 표시됨

**변경 후**:
```typescript
export const CONTACT_INFO = {
  phone: "043-237-7824",
  email: "kesri0728@naver.com",
  address: "충북 청주시 서원구 남이면 양촌 3길 7-30 (28805)",
  coordinates: {
    latitude: 36.566807,
    longitude: 127.489487,
  },
  // ✨ 새로 추가된 지도 URL들 (단일 소스)
  googleMapsEmbed: "https://www.google.com/maps?q=충북+청주시+서원구+남이면+양촌3길+7-30&z=17&output=embed",
  googleMapsSearch: "https://www.google.com/maps/search/?api=1&query=충북+청주시+서원구+남이면+양촌3길+7-30",
  kakaoMapEmbed: "https://map.kakao.com/link/map/한국환경안전연구소,36.566807,127.489487",
  kakaoMapTo: "https://map.kakao.com/link/to/한국환경안전연구소,36.566807,127.489487",
};
```

**개선 효과**:
- ✅ 주소 기반 embed로 플러스코드 노출 최소화
- ✅ zoom=17로 건물 단위 식별 가능
- ✅ 모든 지도 URL이 한 곳에서 관리됨

### 2. CTA 섹션 중복 제거

#### 문제 상황
서비스 페이지를 스크롤하면:
1. 페이지 내 `<ServiceCta />` (서비스별 맞춤 문구)
2. Footer의 공통 CTA 섹션

→ 사용자가 **2개의 문의 섹션**을 연속으로 보게 됨

#### 해결 방법

**변경 파일: `src/components/layout/Footer.tsx`**

```tsx
import { useLocation } from "react-router-dom";

const Footer = () => {
  const location = useLocation();
  
  // 서비스 페이지에서는 Footer CTA 숨김
  const showCta = !location.pathname.startsWith('/services/');
  
  return (
    <footer>
      {/* CTA 섹션 */}
      {showCta && (
        <div className="relative">
          {/* 브랜드 블루 그라데이션 CTA */}
        </div>
      )}
      
      {/* 일반 Footer 정보 */}
    </footer>
  );
};
```

**적용 결과**:
- ✅ `/services/*` 페이지: ServiceCta만 표시, Footer CTA 숨김
- ✅ `/about/*`, `/contact`, `/` 등: Footer CTA 정상 표시
- ✅ 중복 인상 제거

---

**변경 파일: `src/components/common/ServiceCta.tsx`**

```tsx
interface ServiceCtaProps {
  message?: string;      // CTA 헤드라인
  subtitle?: string;     // ✨ 새로 추가: 서브타이틀
}

export default function ServiceCta({ message, subtitle }: ServiceCtaProps) {
  return (
    <section style={CTA_BG}>
      {/* overlay를 bg-black/10으로 조정 (브랜드 블루 강조) */}
      <div className="absolute inset-0 bg-black/10 pointer-events-none"></div>
      
      <h3>{message || "전문가와 상담이 필요하신가요?"}</h3>
      <p>{subtitle || "한국환경안전연구소의 전문 상담원이 신속하고 정확하게 안내해 드립니다."}</p>
      
      {/* 전화/상담 버튼 */}
    </section>
  );
}
```

**z-index 수정**:
- Before: `-z-10`으로 배경이 숨겨짐 (회색으로 보임)
- After: section에 직접 `style={CTA_BG}` 적용

### 3. 브랜드 톤 및 가독성 개선

#### CTA 배경색 개선

**Before** (회색으로 보임):
- z-index 문제로 그라데이션 미적용
- overlay가 너무 어두움 (bg-black/25)

**After**:
```tsx
// 브랜드 블루 그라데이션
const CTA_BG = {
  background: "linear-gradient(90deg, rgba(0,105,255,1) 0%, rgba(30,64,175,1) 55%, rgba(2,132,199,1) 100%)",
};

// overlay 10%로 조정 (브랜드 컬러 살림)
<div className="absolute inset-0 bg-black/10 pointer-events-none"></div>

// text-shadow로 가독성 확보
<h3 className="[text-shadow:_0_2px_8px_rgba(0,0,0,0.25)]">...</h3>
```

**개선 효과**:
- ✅ 브랜드 블루가 선명하게 표시
- ✅ text-shadow로 가독성 확보
- ✅ "공공기관 신뢰 + 현대적" 인상 유지
