# 한국환경안전연구소 웹사이트 프로젝트 완료 보고서

## 1. 프로젝트 개요

### 1.1 프로젝트 정보

- **프로젝트명**: 한국환경안전연구소 공식 웹사이트 리뉴얼
- **발주처**: 한국환경안전연구소 (KESRI)
- **프로젝트 기간**: 2025년 12월
- **프로젝트 버전**: v3.0.0
- **배포 환경**: Vercel (Production)
- **접속 URL**: https://ketri-project-01.vercel.app

### 1.2 프로젝트 목적

한국환경안전연구소의 디지털 전환을 위한 공식 웹사이트 전면 리뉴얼을 통해 다음 목표를 달성하였습니다:

1. **전문성 강화**: 산업보건, 먹는물 검사, 석면조사, 실내공기질 측정 등 전문 서비스의 체계적 정보 제공
2. **사용자 경험 개선**: 현대적 UI/UX 디자인 적용 및 모바일 완벽 지원
3. **업무 효율화**: 관리자 시스템을 통한 콘텐츠 관리 자동화
4. **기술 현대화**: 최신 웹 기술 스택 적용 및 확장 가능한 아키텍처 구축

## 5. 배포 및 운영 상태

### 5.1 배포 환경

#### Production 환경
- **플랫폼**: Vercel
- **배포 URL**: https://ketri-project-01.vercel.app
- **빌드 도구**: Vite
- **Framework Preset**: Vite
- **출력 디렉토리**: dist
- **빌드 명령어**: npm run build

#### 환경 변수 설정
다음 환경변수가 Vercel에 설정되어 있습니다:
- `VITE_FIREBASE_API_KEY`: Firebase API 키
- `VITE_FIREBASE_AUTH_DOMAIN`: Firebase 인증 도메인
- `VITE_FIREBASE_PROJECT_ID`: Firebase 프로젝트 ID
- `VITE_FIREBASE_STORAGE_BUCKET`: Firebase Storage 버킷
- `VITE_FIREBASE_MESSAGING_SENDER_ID`: Firebase 메시징 ID
- `VITE_FIREBASE_APP_ID`: Firebase 앱 ID
- `VITE_FIREBASE_MEASUREMENT_ID`: Firebase Analytics ID
- `VITE_ADMIN_EMAILS`: 관리자 이메일 목록 (쉼표 구분)

### 5.2 배포 프로세스

#### 자동 배포 파이프라인
1. GitHub 저장소에 코드 push
2. Vercel이 자동으로 변경사항 감지
3. 빌드 프로세스 실행
4. 빌드 성공 시 자동 배포
5. 배포 완료 알림

#### 수동 배포 (Vercel CLI)
```bash
# 프로덕션 배포
vercel --prod

# 프리뷰 배포
vercel
```
