## 1. 관리자 로그인

### 1.1 관리자 권한 부여 방식

관리자 권한은 **이메일 주소 기반**으로 자동 부여됩니다.

#### 권한 부여 절차

**Step 1: 환경변수 등록**
- Vercel 관리자가 `VITE_ADMIN_EMAILS` 환경변수에 관리자 이메일 등록
- 형식: `admin@ketri.co.kr,manager@ketri.co.kr` (쉼표로 구분)

**Step 2: 회원가입**
- 등록된 이메일로 회원가입 진행
- 일반 회원가입 절차와 동일

**Step 3: 자동 권한 부여**
- 로그인 시 시스템이 이메일 확인
- 환경변수 목록과 매칭되면 자동으로 관리자 권한 부여
- 관리자 메뉴 자동 표시

### 1.2 로그인 방법

#### 로그인 페이지 접속
```
URL: https://ketri-project-01.vercel.app/auth/login
```

#### 로그인 절차
1. 이메일 주소 입력 (관리자로 등록된 이메일)
2. 비밀번호 입력
3. "로그인" 버튼 클릭
4. 자동으로 관리자 페이지로 이동

### 1.3 로그인 문제 해결

#### 로그인 실패 시
- 이메일 주소 정확히 확인
- 비밀번호 확인 (대소문자 구분)
- "비밀번호 찾기" 기능 사용

#### 관리자 권한 없는 경우
- 환경변수에 이메일이 등록되었는지 확인
- 기술 담당자에게 문의하여 권한 추가 요청

## 3. 공지사항 관리

### 3.1 새 공지사항 작성

#### Step 1: 작성 화면 이동
1. 관리자 페이지 접속
2. "공지사항 관리" 클릭
3. "새 소식 작성" 버튼 클릭

#### Step 2: 정보 입력

**제목 입력**
- 명확하고 간결한 제목 작성
- 예시: "2026년 설 연휴 휴무 안내"

**카테고리 선택**

| 카테고리 | 배지 색상 | 사용 시기 |
|---------|----------|----------|
| 중요 | 빨간색 | 중요 공지, 정책 변경 |
| 일반 | 파란색 | 일반 소식, 안내사항 |
| 이벤트 | 녹색 | 행사, 이벤트, 세미나 |
| 긴급 | 주황색 | 긴급 공지, 시스템 점검 |

**내용 입력**
- 본문 내용을 자세히 작성
- 줄바꿈은 Enter 키 사용
- 공백 2개로 줄바꿈 강제 가능

**핀 고정**
- "핀 고정" 체크박스 선택 시 목록 최상단에 고정
- 중요 공지를 강조할 때 사용
- 너무 많이 고정하지 않도록 주의 (3개 이하 권장)

#### Step 3: 저장
- "저장" 버튼 클릭
- 저장 완료 후 목록 페이지로 자동 이동
- 작성일시 및 작성자 자동 기록

### 3.2 공지사항 수정

#### Step 1: 수정할 공지사항 찾기
1. 공지사항 목록에서 수정할 항목 찾기
2. "수정" 버튼 클릭

#### Step 2: 내용 수정
- 제목, 카테고리, 내용 수정 가능
- 핀 고정 여부 변경 가능
- 작성일시와 작성자는 수정 불가

#### Step 3: 저장
- "저장" 버튼 클릭
- 수정 완료 후 목록 페이지로 이동

### 3.3 공지사항 삭제

⚠️ **주의**: 삭제된 공지사항은 복구할 수 없습니다.

#### 삭제 절차
1. 공지사항 목록에서 삭제할 항목 찾기
2. "삭제" 버튼 클릭
3. 확인 팝업에서 "확인" 클릭
4. 목록에서 즉시 제거

### 3.4 핀 고정 활용 가이드

#### 효과적인 사용
✅ **권장 사용 예시**
- "홈페이지 리뉴얼 안내" (신규 공지)
- "2026년 설 연휴 휴무 안내" (기간 한정)
- "긴급 공지: 시스템 점검" (긴급 상황)

❌ **비권장 사용 예시**
- 모든 공지사항을 핀 고정 (의미 없음)
- 오래된 공지를 계속 핀 고정 (정보 혼란)
- 5개 이상 동시 핀 고정 (가독성 저하)

#### 핀 고정 관리 원칙
- **최대 3개**: 동시에 핀 고정할 공지는 3개 이하
- **정기 검토**: 매주 핀 고정 목록 검토 및 해제
- **명확한 기준**: 정말 중요한 공지만 고정

## 4. 운영 주의사항

### 4.1 콘텐츠 작성 가이드

#### 제목 작성

✅ **좋은 예시**
- "2026년 설 연휴 휴무 안내"
- "먹는물 검사 수수료 조정 안내"
- "신규 장비 도입 완료"

❌ **나쁜 예시**
- "공지" (불명확)
- "!!!중요!!!" (과도한 기호)
- "클릭하세요" (행동 유도 부적절)

#### 본문 작성

✅ **권장 사항**
- 명확하고 간결한 문장
- 필요한 정보 빠짐없이 기재
- 날짜, 시간, 장소 등 구체적 정보 포함
- 문단 나눔으로 가독성 향상

❌ **주의 사항**
- 과도하게 긴 문장 (가독성 저하)
- 전문 용어 남발 (이해 어려움)
- 불필요한 감탄사 (전문성 저하)
- 오탈자 및 맞춤법 오류

### 4.2 카테고리 선택 기준

#### 중요 (빨간색)
- 회사 주요 정책 변경
- 중대한 안내사항
- 모든 직원이 알아야 할 정보

#### 일반 (파란색)
- 일상적인 공지사항
- 일반 안내사항
- 정보성 콘텐츠

#### 이벤트 (녹색)
- 세미나, 교육, 행사
- 기념일 관련 소식
- 이벤트 및 프로모션

#### 긴급 (주황색)
- 시스템 점검
- 긴급 상황 안내
- 즉시 확인 필요한 정보

### 4.3 수정 금지 영역

다음 항목은 **절대 수정하지 마세요**:

❌ **수정 금지**
- 웹사이트 코드 파일
- Firebase 설정
- Vercel 배포 설정
- 환경변수 (VITE_ADMIN_EMAILS 제외)
- GitHub 저장소 파일

✅ **수정 가능**
- 공지사항 내용
- 카테고리 선택
- 핀 고정 설정

### 4.4 배포 및 반영

**자동 반영**
- 공지사항 작성/수정/삭제는 즉시 반영
- 별도의 배포 절차 불필요
- 새로고침으로 바로 확인 가능

**확인 방법**
1. 공지사항 작성/수정 후 저장
2. 홈페이지로 이동
3. 공지사항 목록에서 확인
4. 필요 시 브라우저 새로고침 (Ctrl+F5)

## 5. 문제 해결

### 5.1 로그인 문제

#### 증상: 로그인 버튼을 눌러도 반응 없음
**원인**: 네트워크 오류 또는 Firebase 연결 문제  
**해결**: 브라우저 새로고침 후 재시도, Wi-Fi 연결 확인

#### 증상: "잘못된 이메일 또는 비밀번호" 오류
**원인**: 이메일 또는 비밀번호 오류  
**해결**: 이메일 주소 재확인, 비밀번호 찾기 기능 사용

#### 증상: 로그인은 되지만 관리자 메뉴가 안 보임
**원인**: 관리자 권한 미부여  
**해결**: 기술 담당자에게 이메일 등록 요청

### 5.2 공지사항 작성 문제

#### 증상: 저장 버튼을 눌러도 저장 안 됨
**원인**: 제목 또는 내용 미입력  
**해결**: 제목과 내용 모두 입력 후 저장

#### 증상: 작성한 공지사항이 목록에 안 보임
**원인**: 캐시 문제  
**해결**: 브라우저 새로고침 (Ctrl+F5), 다른 브라우저에서 확인

#### 증상: 삭제 버튼이 안 보임
**원인**: 권한 문제 또는 다른 사람이 작성한 글  
**해결**: 자신이 작성한 글인지 확인, 관리자 권한 재확인

### 5.3 화면 표시 문제

#### 증상: 화면이 깨져 보임
**원인**: 브라우저 호환성 문제  
**해결**: 최신 Chrome, Edge, Safari 사용 권장

#### 증상: 다크모드에서 글자가 안 보임
**원인**: 브라우저 캐시 문제  
**해결**: 캐시 삭제 후 재접속

#### 증상: 모바일에서 버튼이 너무 작음
**원인**: 확대/축소 설정 문제  
**해결**: 브라우저 확대 수준 100% 확인

### 5.4 긴급 상황 대응

#### 웹사이트 접속 불가
1. 다른 기기에서 접속 시도
2. Wi-Fi 연결 확인
3. Vercel 상태 확인 (status.vercel.com)
4. 기술 담당자 연락

#### 잘못된 공지사항 게시
1. 즉시 해당 공지사항 삭제
2. 필요 시 정정 공지사항 작성
3. 이메일 또는 전화로 추가 안내

#### 관리자 계정 접근 불가
1. 비밀번호 찾기 시도
2. 다른 관리자 계정으로 접속
3. 기술 담당자에게 긴급 연락

## 6. 운영 팁

### 6.1 효율적인 공지사항 관리

**정기 점검 (주 1회)**
- 핀 고정된 공지사항 검토
- 오래된 공지사항 아카이브 고려
- 조회수 확인 및 중요도 재평가

**작성 시 체크리스트**
- ✅ 제목 명확한가?
- ✅ 카테고리 적절한가?
- ✅ 본문 오탈자 없는가?
- ✅ 필요한 정보 모두 포함되었는가?
- ✅ 핀 고정 필요한가?

### 6.2 브라우저 권장 사항

**권장 브라우저**
- Chrome (최신 버전)
- Microsoft Edge (최신 버전)
- Safari (최신 버전)

**비권장 브라우저**
- Internet Explorer (지원 종료)
