## 1. 관리자 로그인

### 1.1 관리자 권한 부여 방식

관리자 권한은 **이메일 주소**를 기반으로 자동 부여됩니다.

#### 권한 부여 절차

1. **환경변수 설정**: Vercel 관리자가 `VITE_ADMIN_EMAILS` 환경변수에 관리자 이메일을 등록합니다.
   ```
   예시: admin@ketri.co.kr,manager@ketri.co.kr
   ```

2. **회원가입**: 등록된 이메일로 회원가입을 진행합니다.

3. **자동 권한 부여**: 로그인 시 자동으로 관리자 권한이 부여됩니다.

### 1.2 로그인 방법

#### Step 1: 로그인 페이지 접속
```
URL: https://ketri-project-01.vercel.app/auth/login
```

#### Step 2: 이메일과 비밀번호 입력
- 관리자로 등록된 이메일 주소 입력
- 비밀번호 입력
- "로그인" 버튼 클릭

#### Step 3: 관리자 페이지 이동
- 로그인 성공 시 자동으로 관리자 페이지로 이동
- 우측 상단에 사용자 이름 표시

### 1.3 로그인 문제 해결

#### 로그인이 안 될 경우
1. 이메일 주소를 정확히 입력했는지 확인
2. 비밀번호가 정확한지 확인
3. "비밀번호 찾기"를 통해 비밀번호 재설정

#### 관리자 권한이 없는 경우
1. 환경변수에 이메일이 등록되어 있는지 확인
2. 기술 담당자에게 문의하여 권한 추가 요청

## 3. 공지사항 관리

### 3.1 새 공지사항 작성

#### Step 1: 작성 화면 이동
1. 관리자 페이지 접속
2. "공지사항 관리" 클릭
3. "새 소식 작성" 버튼 클릭

#### Step 2: 공지사항 정보 입력

**제목 입력**
- 명확하고 간결한 제목 작성
- 예시: "2026년 설 연휴 휴무 안내"

**카테고리 선택**
- **중요**: 주요 공지사항 (빨간색 배지)
- **일반**: 일반 공지사항 (파란색 배지)
- **이벤트**: 이벤트 소식 (녹색 배지)
- **긴급**: 긴급 공지사항 (주황색 배지)

**내용 입력**
- 본문 내용을 자세히 작성
- 줄바꿈은 Enter 키로 입력
- 마크다운 문법 지원 (향후)

**핀 고정**
- "핀 고정" 체크박스 선택 시 목록 최상단에 고정 표시

#### Step 3: 저장
- "저장" 버튼 클릭
- 저장 완료 후 목록 페이지로 자동 이동

### 3.2 공지사항 수정

#### Step 1: 수정할 공지사항 찾기
1. 공지사항 목록에서 수정할 항목 찾기
2. 해당 항목의 "수정" 버튼 클릭

#### Step 2: 내용 수정
- 제목, 카테고리, 내용 수정
- 핀 고정 여부 변경 가능

#### Step 3: 저장
- "저장" 버튼 클릭
- 수정 완료 후 목록 페이지로 이동

### 3.3 공지사항 삭제

#### 주의사항
⚠️ **삭제된 공지사항은 복구할 수 없습니다.**

#### 삭제 절차
1. 공지사항 목록에서 삭제할 항목 찾기
2. "삭제" 버튼 클릭
3. 확인 팝업에서 "확인" 클릭
4. 목록에서 즉시 제거됨

### 3.4 카테고리별 배지 색상

| 카테고리 | 배지 색상 | 사용 시기 |
|---------|----------|----------|
| 중요 | 빨간색 | 중요한 공지사항, 정책 변경 |
| 일반 | 파란색 | 일반적인 소식, 안내사항 |
| 이벤트 | 녹색 | 행사, 이벤트, 세미나 |
| 긴급 | 주황색 | 긴급 공지, 시스템 점검 |

### 3.5 핀 고정 활용

#### 핀 고정의 효과
- 목록 최상단에 항상 표시
- "📌" 아이콘으로 구분
- 중요 공지를 강조할 때 사용

#### 사용 예시
```
✅ 좋은 사용:
- "홈페이지 리뉴얼 안내" (핀 고정)
- "2026년 설 연휴 휴무 안내" (핀 고정)

❌ 나쁜 사용:
- 모든 공지사항을 핀 고정 (의미 없음)
- 오래된 공지를 계속 핀 고정 (정보 혼란)
```

## 5. 문제 해결 가이드

### 5.1 자주 묻는 질문 (FAQ)

#### Q1. 공지사항 작성 후 저장이 안 돼요.
**A1.** 다음 사항을 확인하세요:
1. 제목과 내용을 모두 입력했는지 확인
2. 인터넷 연결 상태 확인
3. 브라우저를 새로고침한 후 다시 시도
4. 문제가 계속되면 기술 담당자에게 문의

#### Q2. 공지사항이 목록에 표시되지 않아요.
**A2.** 다음 사항을 확인하세요:
1. 작성 후 "저장" 버튼을 클릭했는지 확인
2. 페이지를 새로고침해보세요 (F5 또는 Ctrl+R)
3. 다른 브라우저에서도 확인해보세요

#### Q3. 삭제한 공지사항을 복구할 수 있나요?
**A3.** 아니요, 삭제된 공지사항은 복구할 수 없습니다.
- 삭제 전 신중하게 확인하세요
- 중요한 공지사항은 백업해두는 것을 권장합니다

#### Q4. 관리자 권한이 갑자기 사라졌어요.
**A4.** 다음 절차를 따르세요:
1. 로그아웃 후 다시 로그인
2. 관리자 이메일로 로그인했는지 확인
3. 문제가 계속되면 기술 담당자에게 문의

#### Q5. 다크모드에서 글자가 안 보여요.
**A5.** 
- 헤더 우측의 다크모드 토글 버튼으로 라이트모드로 전환하세요
- 모든 페이지에서 라이트/다크 모드가 정상 작동합니다

### 5.2 브라우저별 권장사항
