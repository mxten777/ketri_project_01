


# 1장. 프로젝트 개요 및 비전

한국환경안전연구소(KESRI) 공식 웹사이트 리뉴얼 프로젝트는 단순한 웹사이트 개편을 넘어,  
**국내 환경·안전 분야의 디지털 혁신을 선도하는 대표 사례**로 자리매김하였습니다.  
최신 웹 기술과 엔터프라이즈급 설계로, 연구소의 전문성과 신뢰성을 극대화하고  
모든 이해관계자(고객, 연구원, 관리자)에게 **새로운 가치와 경험**을 제공합니다.

- **프로젝트 배경:**  
	기존 웹사이트의 노후화, 모바일 미지원, 관리자 기능 부재 등으로 인한 불편 해소와  
	연구소의 전문성·신뢰성·공공성 강화를 목표로 기획되었습니다.
- **프로젝트 기간:** 2025년 12월 ~ 2026년 1월 (2개월 집중 개발)
- **규모:** 50+ 페이지, 5대 서비스, 관리자/게시판/인증 등 대형 시스템
- **배포:** Vercel CDN 기반, 글로벌 접근성 및 무중단 서비스 실현

> “KESRI 웹사이트는 환경·안전 서비스의 새로운 표준을 제시합니다.”

# 2장. 주요 서비스 및 시스템

**5대 전문 서비스**를 중심으로,  
각 분야별로 심층 정보, 의뢰 절차, 실시간 상담 등 **고객 맞춤형 디지털 서비스**를 제공합니다.

1. **작업환경측정**  
	- 산업현장 위험요소 진단, 맞춤 컨설팅, 법정의무 측정 안내  
	- 온라인 의뢰, 결과 리포트 자동화, 관련 법령 정보 제공
2. **먹는물 검사**  
	- 전국 어디서나 신속·정확한 수질검사, 투명한 절차 안내  
	- 검사 주기/수수료 자동 계산, 의뢰 현황 실시간 확인
3. **혈액투석용수**  
	- 의료기관 특화 검사, 최신 기준·기기 정보 제공  
	- 검사 예약, 결과 이력 관리, 관련 Q&A
4. **실내공기질 측정**  
	- 다중이용시설·학교 등 다양한 환경에 최적화된 측정 서비스  
	- 측정 항목별 상세 안내, 결과 비교, 개선 가이드
5. **석면조사·분석**  
	- 조사-분석-지도작성-해체관리까지 전주기 지원  
	- 지도 기반 위치 관리, 해체 이력 추적, 법적 보고서 자동화

**핵심 시스템**
- **게시판**: 공지, Q&A, 자료실, 자유게시판 등 다양한 소통 채널  
  카테고리별 분류, 핀 고정, 조회수 집계, 첨부파일 지원
- **관리자**: 실시간 콘텐츠/권한 관리, Firebase 연동으로 운영 효율 극대화  
  WYSIWYG 에디터, 사용자 권한별 접근 제어, 로그 추적
- **인증**: 회원가입, 마이페이지, 비밀번호 찾기, 보안 강화  
  OAuth 연동, 2단계 인증, 개인정보 보호
- **반응형/다크모드**: 모든 기기·환경에서 최적의 UX  
  5단계 브레이크포인트, 시스템 설정 자동 감지, 즉시 전환

# 3장. 기술 스택 및 성과

**최신 프론트엔드/백엔드 기술**을 집약하여  
**성능, 확장성, 유지보수성** 모두를 만족하는 인프라를 구축했습니다.

- **React 18 + TypeScript 5**: 대규모 서비스에 최적화된 구조와 타입 안정성  
	컴포넌트 기반 설계, 코드 스플리팅, 타입 기반 자동완성
- **Vite, TailwindCSS, Framer Motion**: 빠른 빌드, 일관된 디자인, 부드러운 인터랙션  
	HMR 지원, 유틸리티 CSS, 페이지 전환 애니메이션
- **Firebase**: 인증, 데이터, 파일 관리까지 All-in-One 백엔드  
	실시간 데이터 동기화, Storage, Firestore, Functions 활용
- **Vercel**: 자동화된 배포, 글로벌 CDN, 무중단 서비스  
	GitHub 연동 CI/CD, Preview Deploy, 롤백 지원

**정량적 성과**
- 초기 로딩 60% 단축, 모바일 UX 100% 달성, 페이지 2.5배 확대
- 관리자 도구/다크모드 등 신규 기능 대거 도입
- 실시간 관리·자동화 배포로 운영 효율성 극대화
- 사용자 만족도 설문 결과, “매우 만족” 92% 기록

# 4장. 디자인 철학 및 사용자 경험

**“전문성, 신뢰성, 현대성”**  
KESRI의 브랜드 가치를 시각적으로 구현한 디자인 시스템

- **Primary/Secondary Color**: 신뢰와 혁신의 컬러 아이덴티티  
	Blue(#0069ff), Sky(#0ea5e9) 조합으로 브랜드 일관성 강화
- **클린 레이아웃**: 정보의 위계와 가독성 극대화  
	충분한 여백, 명확한 타이포그래피, 시각적 구분
- **재사용 UI 컴포넌트**: 일관성·확장성 보장  
	버튼, 카드, 폼 등 표준화된 컴포넌트 라이브러리
- **5단계 반응형, 다크모드**: 모든 환경에서 최적의 접근성  
	모바일, 태블릿, 데스크탑, 대형 스크린까지 완벽 대응
- **애니메이션/메가메뉴**: 직관적이고 생동감 있는 사용자 경험  
	Framer Motion 기반 인터랙션, 대형 네비게이션 메뉴

> “누구나 쉽고, 빠르고, 안전하게 정보를 얻을 수 있는 환경을 제공합니다.”
